# Privacy Policy for Desktop Client 1

Last updated: October 31, 2026

Desktop Client 1 is a personal tool, used only by its owner, that reads Google Drive files to run sports betting models.

## Information the app accesses

When you sign in with Google and grant permission, the app can read files in Google Drive, Google Docs, and Google Sheets. It reads only the files needed to run the models.

## How the information is used

Data from these files is used only to run the owner's sports betting models. It is not used for advertising, profiling, or any other purpose.

## Sharing

The app does not sell, share, or transfer Google user data to anyone. No data is sent to third parties.

## Storage and security

Data is processed on the owner's own devices and accounts. The app does not keep a separate copy of Google user data beyond what the models need while running.

## Google API Services User Data Policy

The app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

## Revoking access

You can remove the app's access at any time from your Google Account under Security, then Third-party apps and services.
